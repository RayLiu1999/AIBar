# 主畫面採一般視窗，不採托盤彈出面板

AIBar 原本規劃仿 macOS 選單列工具，點托盤圖示彈出貼近圖示的無邊框面板、點外面即關閉。原型（2026-11-09）證實在 Windows 上做得到，但很脆弱：Slint 的托盤 `clicked` 不帶座標，必須透過 Slint 未公開的內部視窗類別名稱呼叫 `Shell_NotifyIconGetRect` 才能貼近圖示；失焦關閉要先手動搶前景焦點，再加上計時防護，避免「點圖示關閉後又立刻重開」；每次重建視窗都會先以預設大小出現再縮放，導致位置跳動與畫面殘缺。因此改為一般視窗：有標題列、可拖動與縮放、記住位置，托盤左鍵切換顯示，X 或 Esc 隱藏回托盤。代價是少了「貼著圖示彈出、點外面就消失」的輕快感，且視窗會在工作列佔一個按鈕。

## Considered Options

- 維持彈出面板：手感最接近 CodexBar，但依賴 Slint 內部細節，Slint 改版就可能失效，焦點與定位問題也難以根治。
- 彈出面板加「釘選」：未釘選時仍是彈出面板，複雜度與脆弱性都還在。
- 一般視窗（採用）：Windows 原生行為，不需特殊技巧；Provider 變多時可縮放與捲動，也能邊看邊做其他事。

# 托盤改顯示焦點 Provider 的剩餘數字，並新增設定視窗

原本托盤圖示只用顏色（綠、黃、紅、灰）表示所有 Provider 的最高用量，實際使用時不看說明就看不懂，也分不出是哪一家。改為在圖示中央直接寫「剩幾 %」，外框用 Provider 代表色表示是哪一家；代表哪一家由主視窗頁籤決定（總覽時為排序第一的 Provider），做法參考 CodexBar 在 macOS 選單列的行為。Windows 托盤只能放約 16–24px 的圖示、旁邊不能放文字，因此把 macOS 上「logo＋文字」的資訊壓成「代表色外框＋數字」，細節（哪個額度視窗、何時重置）交給 Tooltip。

同時推翻規格原本「不做設定視窗、設定只放右鍵選單」的決定：Provider 排序、顯示方式（剩餘／已使用）等設定不適合放在選單勾選項，選單也會隨 Provider 增加而變長。右鍵選單只留立即刷新、設定、關於、結束。

## Considered Options

- 只用顏色（原做法）：抽象，需要看說明才懂，也看不出是哪一家。
- 電量條圖示：直覺，但 16px 下讀不出精確值，且容易與系統電池圖示混淆。
- 每個 Provider 各一個托盤圖示：一眼看到每家，但 Provider 一多就佔滿托盤。
- 數字＋代表色外框、跟隨頁籤（採用）：不看說明也懂，同時表達是哪一家；代價是一次只看得到一家，其他家要看 Tooltip 或開視窗。
